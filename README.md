# walkable-ai-concierge

AI-powered personalised walking challenge recommendations for Walkable.

| Path | What it is |
|---|---|
| [`packages/walkable_ai_concierge`](packages/walkable_ai_concierge) | Reusable Flutter package: the AI Concierge UI |
| [`packages/walkable_ai_concierge/example`](packages/walkable_ai_concierge/example) | Standalone demo app using mock data |

**Status:** UI demo. All recommendations are mock data. No AI model, backend or credentials are included.

```sh
cd packages/walkable_ai_concierge/example
flutter run
```
